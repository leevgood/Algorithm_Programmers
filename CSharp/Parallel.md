# 평행한 직선 찾기 (Parallel Lines) — C# LINQ & Python

## 1. 문제 설명

서로 다른 네 점의 좌표가 담긴 `dots`가 주어진다.

```text
[[x1, y1], [x2, y2], [x3, y3], [x4, y4]]
```

네 점을 **서로 겹치지 않는 두 쌍**으로 나누어 각각 직선을 만들었을 때, 두 직선이 평행하거나 일치하는 경우가 하나라도 있으면 `1`, 그렇지 않으면 `0`을 반환한다.

### 제한사항

- 점의 개수: 4개
- 좌표: 정수, `0 ≤ x, y ≤ 100`
- 같은 좌표를 갖는 점은 없음
- 두 직선이 **일치하는 경우에도 `1`** 반환
- 임의의 두 점을 이은 직선이 x축 또는 y축과 평행한 경우는 입력되지 않음

### 입출력 예시

| dots | result |
|---|---:|
| `[[1, 4], [9, 2], [3, 8], [11, 6]]` | `1` |
| `[[3, 5], [4, 1], [2, 4], [5, 10]]` | `0` |

---

## 2. 핵심 아이디어 (Key Concepts)

네 점을 `A`, `B`, `C`, `D`라고 하면, 두 쌍으로 나누는 방법은 **세 가지**뿐이다.

1. `AB`와 `CD`
2. `AC`와 `BD`
3. `AD`와 `BC`

직선 `P₁P₂`와 `P₃P₄`의 기울기가 같으면 두 직선은 평행하거나 일치한다.

\[
\frac{y_2-y_1}{x_2-x_1}=\frac{y_4-y_3}{x_4-x_3}
\]

나눗셈 대신 **교차 곱셈 (Cross Multiplication)**을 적용한다.

\[
(y_2-y_1)(x_4-x_3)=(y_4-y_3)(x_2-x_1)
\]

이 방법은 실수형 오차를 피하고, 이 문제의 정수 좌표 범위에서는 안전하다. 두 직선이 완전히 일치해도 방향 벡터가 평행하므로 같은 조건으로 처리된다.

## 3. C# 정답 코드 — LINQ 활용

프로그래머스의 2차원 정수 배열 매개변수 형식인 **`int[,]`**를 사용한다.

```csharp
using System;
using System.Linq;

public class Solution
{
    public int solution(int[,] dots)
    {
        // 첫 번째 점(인덱스 0)과 연결할 점을 1, 2, 3 중 선택
        return Enumerable.Range(1, 3).Any(i =>
        {
            // 선택하지 않은 두 점을 두 번째 직선의 양 끝점으로 사용
            int[] rest = Enumerable.Range(1, 3)
                                   .Where(j => j != i)
                                   .ToArray();

            int dx1 = dots[i, 0] - dots[0, 0];
            int dy1 = dots[i, 1] - dots[0, 1];

            int dx2 = dots[rest[1], 0] - dots[rest[0], 0];
            int dy2 = dots[rest[1], 1] - dots[rest[0], 1];

            // 나눗셈 없이 두 직선의 기울기 비교
            return dy1 * dx2 == dy2 * dx1;
        }) ? 1 : 0;
    }
}
```

### 주요 C# 문법

| 문법 | 설명 |
|---|---|
| `int[,] dots` | 2차원 정수 배열 선언 |
| `dots[i, 0]` | i번째 점의 x좌표 접근 |
| `Enumerable.Range(1, 3)` | 정수 `1, 2, 3` 생성 |
| `.Where(j => j != i)` | 현재 선택한 인덱스를 제외 |
| `.ToArray()` | 필터링 결과를 배열로 변환 |
| `.Any(predicate)` | 세 경우 중 조건을 만족하는 것이 하나라도 있으면 `true` |
| `조건 ? 1 : 0` | `bool` 결과를 정수 `1` 또는 `0`으로 변환 |

> 참고: `System.Linq`가 필요하다. 일부 플랫폼에서 C# 매개변수 형식이 `int[][]`로 제공된다면 `dots[i, 0]`을 `dots[i][0]` 형태로 바꿔야 한다.

## 4. Python 정답 코드

```python
def solution(dots):
    # 0번 점과 연결할 점을 1, 2, 3 중 선택
    for i in range(1, 4):
        # 남은 두 점으로 두 번째 직선 생성
        j, k = [p for p in range(1, 4) if p != i]

        dx1 = dots[i][0] - dots[0][0]
        dy1 = dots[i][1] - dots[0][1]

        dx2 = dots[k][0] - dots[j][0]
        dy2 = dots[k][1] - dots[j][1]

        # 두 기울기가 같으면 평행 또는 일치
        if dy1 * dx2 == dy2 * dx1:
            return 1

    return 0
```

### 주요 Python 문법

| 문법 | 설명 |
|---|---|
| `range(1, 4)` | 정수 `1, 2, 3` 순회 |
| `[p for p in ... if ...]` | 리스트 컴프리헨션(List Comprehension) |
| `j, k = ...` | 시퀀스 언패킹(Sequence Unpacking) |
| `dots[i][0]` | i번째 점의 x좌표 접근 |
| `return 1` | 평행한 직선 쌍을 찾으면 즉시 종료 |

## 5. 실행 예시 및 풀이 과정

### 예시 1

```text
dots = [[1, 4], [9, 2], [3, 8], [11, 6]]
```

- `A=(1,4)`, `B=(9,2)`, `C=(3,8)`, `D=(11,6)`
- `AC`의 방향 벡터: `(3-1, 8-4) = (2,4)`
- `BD`의 방향 벡터: `(11-9, 6-2) = (2,4)`
- 교차 곱 비교: `4 × 2 == 4 × 2` → `true`

**출력: `1`**

### 예시 2

```text
dots = [[3, 5], [4, 1], [2, 4], [5, 10]]
```

세 가지 연결 방식 중 어느 경우도 기울기가 일치하지 않는다.

**출력: `0`**

---

## 6. 시간 및 공간 복잡도 (Complexity)

- **시간 복잡도: `O(1)`** — 점이 항상 4개이고 검사하는 연결 방식이 3개로 고정됨
- **공간 복잡도: `O(1)`** — 남은 점을 담는 배열도 최대 2개 원소만 가짐

---

## 7. 실무 및 코딩 테스트 팁

- 네 점을 두 선으로 나누는 **3가지 조합을 모두 검사**해야 한다. 인접 인덱스끼리만 연결하면 정답을 놓칠 수 있다.
- 기울기를 `double`로 계산할 필요가 없다. **정수 교차 곱**으로 비교하면 정확하고 간단하다.
- `Any()`는 조건을 만족하는 순간 평가를 중단하는 **단락 평가(Short-Circuit Evaluation)**를 수행한다.
- 일치하는 두 직선도 교차 곱 조건이 성립하므로 별도 분기 처리가 필요 없다.

**핵심 요약:** `3가지 점 쌍 조합` + `방향 벡터의 교차 곱` + `하나라도 일치하면 1`.
