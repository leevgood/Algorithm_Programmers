# 선분 겹침 길이 구하기 — C# LINQ & Python

## 1. 문제 개요

세 개의 선분이 `[[start, end], [start, end], [start, end]]` 형태로 주어집니다. **두 개 이상의 선분이 겹치는 구간의 총길이**를 반환합니다.

- 선분 수: 3개
- 좌표 범위: `-100 ≤ start < end ≤ 100`
- 끝점 하나에서만 만나는 경우에는 길이가 `0`이므로 겹친 길이에 포함되지 않습니다.
- 세 선분이 동시에 겹쳐도 해당 구간의 길이는 **한 번만** 셉니다.

### 입출력 예

| `lines` | 결과 |
|---|---:|
| `[[0, 1], [2, 5], [3, 9]]` | `2` |
| `[[-1, 1], [1, 3], [3, 9]]` | `0` |
| `[[0, 5], [3, 9], [1, 10]]` | `8` |

---

## 2. 핵심 아이디어: 길이가 1인 구간 단위로 검사

모든 끝점이 정수이므로 각 선분 `[a, b]`를 길이가 1인 구간 `[a, a+1)`, `[a+1, a+2)`, …, `[b-1, b)`로 나눌 수 있습니다.

예를 들어 `[0, 3]`은 `[0, 1)`, `[1, 2)`, `[2, 3)`에 해당합니다.

정수 `x`에 대하여 **`start ≤ x < end`**이면 선분이 구간 `[x, x+1)`을 덮는다고 판단합니다.

1. `x = -100`부터 `99`까지 검사합니다. (총 200개 구간)
2. 각 `x`에 대해 해당 단위 구간을 덮는 선분의 개수를 셉니다.
3. 그 개수가 `2` 이상이면 정답에 `1`을 더합니다.

> 선분 쌍별 겹침 길이를 합산하면 세 선분이 동시에 겹치는 구간을 중복 계산할 수 있습니다. 반면 **좌표별로 한 번씩 검사**하면 중복 없이 총길이를 구할 수 있습니다.

### 예시: `[[0, 2], [-3, -1], [-2, 1]]`

| 단위 구간 | 포함하는 선분 개수 | 길이에 반영? |
|---|---:|---|
| `[-3, -2)` | 1 | 아니요 |
| `[-2, -1)` | 2 | 예 (+1) |
| `[-1, 0)` | 1 | 아니요 |
| `[0, 1)` | 2 | 예 (+1) |
| `[1, 2)` | 1 | 아니요 |

따라서 정답은 **`2`**입니다.

## 3. C# 정답 — LINQ 활용

프로그래머스 C#의 2차원 배열 매개변수 `int[,] lines`에 맞춘 코드입니다.

```csharp
using System.Linq;

public class Solution
{
    public int solution(int[,] lines)
    {
        return Enumerable.Range(-100, 200)
            .Count(x => Enumerable.Range(0, lines.GetLength(0))
                .Count(i => lines[i, 0] <= x && x < lines[i, 1]) >= 2);
    }
}
```

### 주요 LINQ 문법

| 문법 | 역할 |
|---|---|
| `Enumerable.Range(-100, 200)` | 정수 `-100`부터 `99`까지 생성 (`시작값`, `개수`) |
| `lines.GetLength(0)` | 2차원 배열의 첫 번째 차원 길이, 즉 선분의 개수 |
| `Enumerable.Range(0, lines.GetLength(0))` | 선분 인덱스 `0, 1, 2` 생성 |
| `lines[i, 0]`, `lines[i, 1]` | `i`번째 선분의 시작점, 끝점 |
| `.Count(i => 조건)` | 조건을 만족하는 선분의 개수를 계산 |
| `.Count(x => 조건)` | 두 개 이상 겹치는 단위 구간의 개수를 계산 |

**중요:** `Enumerable.Range(start, count)`의 두 번째 인자는 **끝값이 아니라 생성할 원소 수**입니다.

### 반복문으로 풀어 쓴 동일한 로직

```csharp
public class Solution
{
    public int solution(int[,] lines)
    {
        int answer = 0;

        for (int x = -100; x < 100; x++)
        {
            int overlapCount = 0;

            for (int i = 0; i < lines.GetLength(0); i++)
            {
                if (lines[i, 0] <= x && x < lines[i, 1])
                    overlapCount++;
            }

            if (overlapCount >= 2)
                answer++;
        }

        return answer;
    }
}
```

LINQ 풀이와 반복문 풀이는 같은 방법이며 결과도 같습니다.

## 4. Python 정답

```python
def solution(lines):
    return sum(
        sum(start <= x < end for start, end in lines) >= 2
        for x in range(-100, 100)
    )
```

### 주요 Python 문법

| 문법 | 역할 |
|---|---|
| `range(-100, 100)` | `-100`부터 `99`까지 순회 |
| `for start, end in lines` | 각 선분의 시작점과 끝점을 언패킹(Unpacking) |
| `start <= x < end` | `[x, x+1)` 구간이 선분에 포함되는지 검사 |
| `sum(조건 for ...)` | `True`를 `1`, `False`를 `0`으로 합산 |
| `sum(... >= 2 for x in ...)` | 겹치는 선분이 2개 이상인 단위 구간 수를 합산 |

### 반복문으로 풀어 쓴 동일한 로직

```python
def solution(lines):
    answer = 0

    for x in range(-100, 100):
        overlap_count = 0

        for start, end in lines:
            if start <= x < end:
                overlap_count += 1

        if overlap_count >= 2:
            answer += 1

    return answer
```

## 5. 단계별 동작: 세 번째 입출력 예

입력: `[[0, 5], [3, 9], [1, 10]]`

| 단위 구간 범위 | 겹치는 선분 개수 | 정답에 반영되는 길이 |
|---|---:|---:|
| `[0, 1)` | 1 | 0 |
| `[1, 3)` | 2 | 2 |
| `[3, 5)` | 3 | 2 |
| `[5, 9)` | 2 | 4 |
| `[9, 10)` | 1 | 0 |

최종 합계는 `2 + 2 + 4 = 8`입니다. 특히 `[3, 5)`는 세 선분이 모두 겹치지만 **한 번만 계산**합니다.

---

## 6. 시간 및 공간 복잡도

좌표를 탐색하는 구간 수를 `R`, 선분 수를 `N`이라고 하면:

- **시간 복잡도:** `O(R × N)` — 각 단위 구간마다 모든 선분을 확인합니다.
- **추가 공간 복잡도:** `O(1)` — 입력을 제외하고 고정 크기 연산만 수행합니다. (LINQ의 작은 열거자 생성은 별도로 취급)
- 이 문제에서는 `R = 200`, `N = 3`이므로 최대 약 **600번의 선분 포함 여부 검사**만 필요합니다.

## 7. 자주 틀리는 부분

1. **끝점 포함 실수:** `start <= x <= end`로 쓰면 마지막에 존재하지 않는 단위 구간까지 셀 수 있습니다. 반드시 `start <= x < end`를 사용합니다.
2. **한 점에서의 접촉:** `[0, 1]`과 `[1, 3]`은 `1`에서 만날 뿐 공통 길이는 `0`입니다.
3. **선분 쌍의 중복 합산:** 세 선분이 겹치는 영역을 여러 번 더하면 오답이 됩니다.
4. **C# 배열 문법 차이:** 프로그래머스의 `int[,]`에서는 `lines[i, 0]`을 사용합니다. `int[][]`일 때만 `lines[i][0]`입니다.

### 테스트 코드 (Python)

```python
assert solution([[0, 1], [2, 5], [3, 9]]) == 2
assert solution([[-1, 1], [1, 3], [3, 9]]) == 0
assert solution([[0, 5], [3, 9], [1, 10]]) == 8
assert solution([[0, 2], [-3, -1], [-2, 1]]) == 2
assert solution([[0, 3], [0, 3], [0, 3]]) == 3
```

## 8. 결론

이 문제는 **선분 자체가 아닌 길이 1인 구간마다 겹치는 선분 수를 계산**하면 쉽게 해결할 수 있습니다. C#에서는 `Enumerable.Range()`와 `Count()`를 조합한 LINQ 풀이가 간결하고, Python에서는 `range()`와 `sum()`을 조합할 수 있습니다.
