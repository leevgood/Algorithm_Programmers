## 1. 문제 개요

각 학생의 **영어 점수와 수학 점수의 평균**으로 등수를 매긴다. 평균이 같은 학생은 **공동 등수**이며, 그만큼 다음 등수는 건너뛴다.

**입력:** `score` — 각 원소가 `[영어 점수, 수학 점수]`인 2차원 정수 배열

**출력:** 입력 순서를 유지한 학생별 등수 배열

**제한:** 학생 수 1~10명, 각 과목 점수 0~100점, 학생의 점수 쌍은 중복되지 않음(단, 평균이 같을 수 있음).

| score | result |
|---|---|
| `[[80,70],[90,50],[40,70],[50,80]]` | `[1,2,4,3]` |
| `[[80,70],[70,80],[30,50],[90,100],[100,90],[100,100],[10,30]]` | `[4,4,6,2,2,1,7]` |

---

## 2. 핵심 아이디어

**평균 대신 영어+수학의 합계를 비교**하면 된다. 모든 학생이 2과목을 응시하므로, 합계가 클수록 평균도 크다. 실수 나눗셈은 필요하지 않다.

> **학생의 등수 = 자신보다 합계가 높은 학생 수 + 1**

같은 합계는 `>` 비교에 포함되지 않으므로 자연스럽게 공동 등수가 된다.

예를 들어 합계가 `[150, 150, 190, 200]`이면 등수는 `[3, 3, 2, 1]`이다.

---

## 3. C# 풀이 — LINQ

```csharp
using System.Linq;

public class Solution
{
    public int[] solution(int[,] score)
    {
        int count = score.GetLength(0);

        // 각 학생의 영어+수학 합계를 계산
        int[] totals = Enumerable.Range(0, count)
            .Select(i => score[i, 0] + score[i, 1])
            .ToArray();

        // 자신보다 합계가 높은 학생 수 + 1 = 등수
        return totals
            .Select(total => totals.Count(other => other > total) + 1)
            .ToArray();
    }
}
```

> **주의:** 프로그래머스 C#의 2차원 정수 배열 매개변수는 일반적으로 `int[,]`이므로 위에서는 이를 사용했다. `int[][]`(재그드 배열)를 사용하는 실행 환경이라면 아래와 같이 바꾸면 된다.

**재그드 배열(`int[][]`) 버전**

```csharp
using System.Linq;

public class Solution
{
    public int[] solution(int[][] score)
    {
        int[] totals = score.Select(s => s[0] + s[1]).ToArray();
        return totals.Select(total => totals.Count(other => other > total) + 1).ToArray();
    }
}
```

### 주요 LINQ 문법

| 문법 | 역할 |
|---|---|
| `Enumerable.Range(0, count)` | 0부터 `count - 1`까지 인덱스 생성 |
| `Select(...)` | 각 원소를 다른 값으로 변환 |
| `Count(condition)` | 조건을 만족하는 원소 개수 계산 |
| `ToArray()` | 결과를 배열로 변환 |
| `GetLength(0)` | 2차원 배열의 첫 번째 차원(행) 길이 |
| `other > total` | 동점은 세지 않고 **더 높은 점수만** 셈 |

## 4. Python 풀이

```python
def solution(score):
    # 영어+수학 합계를 구한다.
    totals = [english + math for english, math in score]

    # 나보다 점수가 높은 학생 수 + 1
    return [sum(other > total for other in totals) + 1 for total in totals]
```

### 주요 Python 문법

| 문법 | 역할 |
|---|---|
| `for english, math in score` | 두 점수를 각각 변수로 꺼내는 언패킹(Unpacking) |
| `[... for ... in ...]` | 리스트 컴프리헨션(List Comprehension) |
| `other > total` | 비교 결과가 `True` 또는 `False` |
| `sum(...)` | Python에서 `True`를 1, `False`를 0으로 합산 |

## 5. 예제 분석

### 예제 1

입력: `[[80,70],[90,50],[40,70],[50,80]]`

| 학생(입력 순서) | 합계 | 평균 | 더 높은 학생 수 | 등수 |
|---|---:|---:|---:|---:|
| 1 | 150 | 75 | 0 | 1 |
| 2 | 140 | 70 | 1 | 2 |
| 3 | 110 | 55 | 3 | 4 |
| 4 | 130 | 65 | 2 | 3 |

결과: `[1, 2, 4, 3]`

### 예제 2

합계: `[150, 150, 80, 190, 190, 200, 40]`

| 학생(입력 순서) | 합계 | 더 높은 학생 수 | 등수 |
|---|---:|---:|---:|
| 1 | 150 | 3 | 4 |
| 2 | 150 | 3 | 4 |
| 3 | 80 | 5 | 6 |
| 4 | 190 | 1 | 2 |
| 5 | 190 | 1 | 2 |
| 6 | 200 | 0 | 1 |
| 7 | 40 | 6 | 7 |

결과: `[4, 4, 6, 2, 2, 1, 7]`

**공동 2등이 두 명이므로 3등은 없고, 공동 4등이 두 명이므로 5등은 없다.**

## 6. 시간 복잡도 및 주의사항

- 학생 수를 `n`이라고 할 때, 각 학생마다 전체 학생을 검사하므로 **시간 복잡도는 O(n²)**이다.
- 합계 배열과 결과 배열에 각각 `n`개 값이 들어가므로 **추가 공간 복잡도는 O(n)**이다.
- 이 문제는 `n ≤ 10`이므로 O(n²) 풀이로 충분하다.
- `>=`를 쓰면 동점자까지 세어서 등수가 잘못된다. 반드시 **`>`**를 사용한다.
- 정렬하면 원래 학생 순서가 달라질 수 있다. 위 풀이는 **입력 순서를 유지**한다.
- 학생의 영어·수학 점수 쌍이 서로 달라도 합계가 같으면 공동 등수다.

## 7. 핵심 암기 문구

> **“합계로 비교하고, 나보다 높은 사람만 세어 1을 더하자!”**

- **평균 비교 → 합계 비교**
- **공동 등수 → `>`만 사용**
- **등수 공식 → `Count(더 높은 점수) + 1`**
- **C# → `Select` + `Count` + `ToArray`**
- **Python → 리스트 컴프리헨션 + `sum`**
