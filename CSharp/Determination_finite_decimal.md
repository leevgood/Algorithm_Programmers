# 유한소수 판별하기 — C# LINQ & Python

## 1. 문제 설명

두 양의 정수 `a`, `b`가 주어졌을 때 분수 `a / b`가 **유한소수**라면 `1`, **무한소수(순환소수)**라면 `2`를 반환합니다.

- 입력 범위: `1 ≤ a, b ≤ 1,000`
- **핵심 조건:** 기약분수의 분모를 소인수분해했을 때 소인수가 **2와 5뿐**이면 유한소수입니다.
- 기약분수의 분모가 `1`이면 정수이므로 유한소수입니다.

| a | b | 결과 | 이유 |
|---:|---:|---:|---|
| 7 | 20 | 1 | 분모 `20 = 2² × 5` |
| 11 | 22 | 1 | 약분하면 `1/2` |
| 12 | 21 | 2 | 약분하면 `4/7`; 소인수 `7` 존재 |
| 4 | 2 | 1 | 약분하면 `2/1`; 정수도 유한소수 |

---

## 2. 핵심 알고리즘

1. `a`와 `b`의 **최대공약수(GCD, Greatest Common Divisor)**를 구합니다.
2. 분모 `b`를 최대공약수로 나누어 **기약분수의 분모**를 구합니다.
3. 그 분모에서 **2로 나눌 수 없을 때까지** 2를 제거합니다.
4. 이어서 **5로 나눌 수 없을 때까지** 5를 제거합니다.
5. 남은 값이 `1`이면 `1`, 그렇지 않으면 `2`를 반환합니다.

> **왜 분모를 약분해야 할까요?** `11/22`의 원래 분모 `22`에는 소인수 `11`이 들어 있지만, 약분하면 `1/2`이므로 유한소수입니다. 약분하지 않으면 오답이 됩니다.

> **왜 2와 5일까요?** 10진법의 밑 `10 = 2 × 5`이므로 기약분수의 분모가 `2^m × 5^n` 꼴일 때만 적절한 `10^k`를 곱해 정수 분자로 표현할 수 있습니다.

## 3. C# 풀이 — LINQ 활용

**LINQ(Language Integrated Query)**의 `Where()`와 `Max()`로 두 수의 공약수 가운데 가장 큰 수를 찾습니다. 이 문제의 입력은 최대 1,000이므로 간결한 LINQ 접근으로도 충분합니다.

```csharp
using System;
using System.Linq;

public class Solution
{
    public int solution(int a, int b)
    {
        // 1부터 min(a, b)까지 중 두 수를 모두 나누는 최대 수를 선택
        int gcd = Enumerable.Range(1, Math.Min(a, b))
                            .Where(n => a % n == 0 && b % n == 0)
                            .Max();

        // 기약분수의 분모
        int denominator = b / gcd;

        // 소인수 2와 5를 모두 제거
        while (denominator % 2 == 0)
            denominator /= 2;

        while (denominator % 5 == 0)
            denominator /= 5;

        return denominator == 1 ? 1 : 2;
    }
}
```

### C# 주요 문법

| 문법 | 의미 |
|---|---|
| `Enumerable.Range(1, n)` | 1부터 n까지 정수 시퀀스 생성 |
| `Math.Min(a, b)` | 두 정수 중 작은 값 반환 |
| `.Where(n => 조건)` | 조건을 만족하는 요소만 필터링 (LINQ) |
| `.Max()` | 시퀀스의 최댓값 반환 |
| `%` | 나머지 연산자; 나누어떨어지는지 확인 |
| `while` | 조건이 참인 동안 반복 |
| `조건 ? 1 : 2` | 삼항 연산자; 조건에 따라 값 선택 |

**참고:** 최대공약수를 LINQ로 구하는 부분은 학습 목적에 적합하지만, 일반적으로는 아래의 **유클리드 호제법**이 더 효율적입니다.

### C# 추가 풀이 — 효율적인 유클리드 호제법

```csharp
public class Solution
{
    public int solution(int a, int b)
    {
        int x = a, y = b;

        // 유클리드 호제법으로 최대공약수 계산
        while (y != 0)
        {
            int remainder = x % y;
            x = y;
            y = remainder;
        }

        int denominator = b / x;

        while (denominator % 2 == 0)
            denominator /= 2;

        while (denominator % 5 == 0)
            denominator /= 5;

        return denominator == 1 ? 1 : 2;
    }
}
```

## 4. Python 풀이 — `math.gcd()` 활용

파이썬 표준 라이브러리 `math.gcd()`를 사용하면 최대공약수를 효율적이고 간결하게 구할 수 있습니다.

```python
from math import gcd


def solution(a, b):
    # 기약분수의 분모 계산
    denominator = b // gcd(a, b)

    # 소인수 2 제거
    while denominator % 2 == 0:
        denominator //= 2

    # 소인수 5 제거
    while denominator % 5 == 0:
        denominator //= 5

    return 1 if denominator == 1 else 2
```

### Python 주요 문법

| 문법 | 의미 |
|---|---|
| `from math import gcd` | 최대공약수 함수 불러오기 |
| `gcd(a, b)` | `a`와 `b`의 최대공약수 |
| `//` | 정수 나눗셈 (몫) |
| `%` | 나머지 연산 |
| `while` | 조건이 참인 동안 반복 |
| `1 if 조건 else 2` | 파이썬 조건부 표현식 |

## 5. 예제별 실행 과정

### 예제 1: `a = 7, b = 20`

- 최대공약수: `gcd(7, 20) = 1`
- 기약분수의 분모: `20 / 1 = 20`
- `20 → 10 → 5` (2를 두 번 제거)
- `5 → 1` (5를 한 번 제거)
- 남은 분모가 `1`이므로 **결과 `1`**

### 예제 2: `a = 11, b = 22`

- 최대공약수: `gcd(11, 22) = 11`
- 기약분수의 분모: `22 / 11 = 2`
- `2 → 1` (2 제거)
- 남은 분모가 `1`이므로 **결과 `1`**

### 예제 3: `a = 12, b = 21`

- 최대공약수: `gcd(12, 21) = 3`
- 기약분수의 분모: `21 / 3 = 7`
- `7`은 2나 5로 나누어떨어지지 않음
- 남은 분모가 `7`이므로 **결과 `2`**

## 6. 시간 및 공간 복잡도

| 풀이 | 시간 복잡도 | 추가 공간 복잡도 |
|---|---|---|
| C# LINQ 최대공약수 | `O(min(a, b) + log b)` | `O(1)`¹ |
| C# 유클리드 호제법 | `O(log min(a, b) + log b)` | `O(1)` |
| Python `math.gcd()` | `O(log min(a, b) + log b)`² | `O(1)`³ |

¹ LINQ 시퀀스는 지연 평가되므로 배열 전체를 생성하지 않습니다. ² 정수 크기를 일정하게 보는 일반적인 알고리즘 분석 기준입니다. ³ 입력 범위의 고정 크기 정수를 가정합니다.

실무나 큰 입력에서는 **유클리드 호제법 / `math.gcd()`**가 더 좋은 선택입니다.

## 8. 정리

- 분수가 유한소수인지 판단할 때는 **먼저 최대공약수로 약분**해야 합니다.
- 기약분수의 **분모에서 2와 5를 모두 제거**한 후 `1`인지 확인합니다.
- **C#:** LINQ의 `Where()` + `Max()`로 최대공약수 구하기를 연습할 수 있습니다.
- **Python:** `math.gcd()`를 활용하는 풀이가 간결하고 효율적입니다.
- **주의:** 정수도 유한소수이므로 기약분수의 분모가 `1`일 때도 `1`을 반환합니다.
