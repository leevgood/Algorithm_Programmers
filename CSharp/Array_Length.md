# 배열의 길이를 2의 거듭제곱으로 만들기

## 문제 설명

정수 배열 `arr`이 주어질 때, 배열의 길이가 **2의 정수 거듭제곱**이 되도록 배열 뒤에 `0`을 최소한으로 추가합니다.

예를 들어 배열의 길이가 `6`이라면 다음 2의 거듭제곱은 `8`이므로 `0`을 2개 추가합니다.

```text
[1, 2, 3, 4, 5, 6]
→
[1, 2, 3, 4, 5, 6, 0, 0]
```

---

## 핵심 아이디어

2의 거듭제곱은 다음과 같습니다.

```text
1, 2, 4, 8, 16, 32, 64, ...
```

배열의 현재 길이를 `n`이라고 할 때,

1. `power = 1`부터 시작합니다.
2. `power`가 `n`보다 작으면 계속 `2`를 곱합니다.
3. `power >= n`이 되는 순간, `power`가 배열이 가져야 할 최소 길이입니다.
4. `power - n`개만큼 배열 뒤에 `0`을 추가합니다.

예를 들어 `arr.Length = 6`이라면:

```text
1 → 2 → 4 → 8
```

따라서 목표 길이는 `8`이고,

```text
8 - 6 = 2
```

이므로 `0`을 2개 추가하면 됩니다.

---

# C# 풀이

## Solution

```csharp
using System;

public class Solution
{
    public int[] solution(int[] arr)
    {
        int length = arr.Length;
        int power = 1;

        // arr의 길이 이상인 가장 작은 2의 거듭제곱 찾기
        while (power < length)
        {
            power *= 2;
        }

        // 목표 길이의 새 배열 생성
        // C#의 int 배열은 기본적으로 0으로 초기화됨
        int[] answer = new int[power];

        // 기존 arr의 값을 새 배열에 복사
        Array.Copy(arr, answer, arr.Length);

        return answer;
    }
}
```

---

## C# 코드 설명

| 코드 | 설명 |
|---|---|
| `arr.Length` | 현재 배열의 길이를 구합니다. |
| `int power = 1` | 2의 거듭제곱을 찾기 위한 시작값입니다. |
| `while (power < length)` | 배열 길이 이상이 될 때까지 반복합니다. |
| `power *= 2` | `1 → 2 → 4 → 8 → ...` 형태로 증가합니다. |
| `new int[power]` | 목표 길이의 새 정수 배열을 만듭니다. |
| `Array.Copy()` | 기존 배열의 데이터를 새 배열로 복사합니다. |

C#에서 `int[]`을 새로 생성하면 모든 원소가 자동으로 `0`으로 초기화됩니다.

따라서 부족한 부분에 직접 `0`을 넣을 필요가 없습니다.

---

## C# 동작 예시

입력:

```csharp
int[] arr = { 1, 2, 3, 4, 5, 6 };
```

배열 길이:

```text
6
```

2의 거듭제곱 탐색:

```text
1
2
4
8
```

목표 길이:

```text
8
```

새 배열:

```text
[0, 0, 0, 0, 0, 0, 0, 0]
```

기존 배열 복사 후:

```text
[1, 2, 3, 4, 5, 6, 0, 0]
```

# Python 풀이

## Solution

```python
def solution(arr):
    length = len(arr)
    power = 1

    # arr의 길이 이상인 가장 작은 2의 거듭제곱 찾기
    while power < length:
        power *= 2

    # 부족한 길이만큼 0 추가
    return arr + [0] * (power - length)
```

---

## Python 코드 설명

| 코드 | 설명 |
|---|---|
| `len(arr)` | 현재 리스트의 길이를 구합니다. |
| `power = 1` | 2의 거듭제곱 탐색을 위한 시작값입니다. |
| `while power < length` | 목표 길이를 찾을 때까지 반복합니다. |
| `power *= 2` | `1 → 2 → 4 → 8 → ...` 형태로 증가합니다. |
| `[0] * n` | `0`이 `n`개 들어 있는 리스트를 만듭니다. |
| `arr + ...` | 기존 리스트 뒤에 0 리스트를 연결합니다. |

---

## Python 동작 예시

입력:

```python
arr = [1, 2, 3, 4, 5, 6]
```

배열 길이:

```text
6
```

다음 2의 거듭제곱:

```text
8
```

추가해야 하는 `0`의 개수:

```text
8 - 6 = 2
```

따라서:

```python
[0] * 2
```

결과:

```text
[1, 2, 3, 4, 5, 6, 0, 0]
```

입력:

```text
[58, 172, 746, 89]
```

현재 길이:

```text
4
```

```text

```

따라서 `0`을 추가할 필요가 없습니다.

결과:

```text

```

# 시간 복잡도

배열의 길이를 `N`이라고 하면, 목표 2의 거듭제곱을 찾는 반복문의 횟수는 대략 다음과 같습니다.

```text
O(log N)
```

하지만 최종 결과 배열을 만들거나 복사하는 과정에서 배열의 원소를 처리해야 하므로 전체 시간 복잡도는:

```text
O(N)
```

공간 복잡도 역시 결과 배열을 새로 생성하므로:

```text
O(N)
```

입니다.

# 정리

이 문제의 핵심은 **현재 배열 길이 이상인 가장 작은 2의 거듭제곱을 찾는 것**입니다.

```text
1 → 2 → 4 → 8 → 16 → 32 → ...
```

현재 길이보다 작으면 계속 2를 곱하고, 처음으로 현재 길이 이상이 되는 값을 목표 길이로 사용하면 됩니다.

### C#

```csharp
while (power < arr.Length)
{
    power *= 2;
}
```

### Python

```python
while power < len(arr):
    power *= 2
```

이후 목표 길이와 현재 길이의 차이만큼 `0`을 채워주면 문제를 해결할 수 있습니다.
